# CSS Anchor Position Demo

## 🔗 Live Demo  
[View Demo →](https://chirag0521.github.io/Day55_anchorEffect/)

## Description  
A simple project using CSS anchor positioning to create a floating highlight box that follows hovered anchor (`<a>`) links. The highlight smoothly moves to the hovered link, creating an elegant hover effect with pure CSS.

##  Technologies Used  
- HTML5  
- CSS (Anchor positioning: `anchor-name`, `position-anchor`, `anchor()`, transitions)
